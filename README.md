# Gramix — веб-клиент

Версия 1.0.12. React 19 + Vite 8. Firebase используется для входа;
данные и анализ фотографий обслуживает отдельный Cloudflare Worker / D1.
Этот репозиторий содержит веб-клиент, а не сервер и не Android-проект.

## Запуск

Нужен Node.js 22.12+ (или совместимая более новая версия).

1. Выполните `npm ci`.
2. Создайте `.env.local` по образцу `.env.example` и заполните публичную конфигурацию Firebase Web App.
3. Выполните `npm run dev`.

`npm test` запускает тесты кеша и хранилища, `npm run build` создаёт `dist/`.
`npm run preview` позволяет проверить сборку локально.
Для браузерного регрессионного теста запустите dev-сервер на порту 5179,
установите Playwright отдельно и выполните `node test/ui-reliability.mjs`.
Можно указать `PLAYWRIGHT_MODULE` и `TEST_CHROME_PATH` для уже установленного окружения.
Тест использует заглушки авторизации и API, не изменяя реальные данные пользователей.

## Размещение

Раздавайте содержимое `dist/` по HTTPS. Настройте возврат `index.html`
для клиентских маршрутов (например, `/main`, `/stats`, `/profile`).
Домен сайта должен быть разрешён в Firebase Authentication и CORS серверного API.
Сам push в GitHub не публикует работающий сайт.

Все переменные с префиксом `VITE_` видны посетителям сайта.
Никогда не добавляйте сюда Telegram-токен, Gemini API key, приватные ключи,
пароли или сервисный аккаунт Firebase. Серверные секреты остаются в Worker.
Нативные интеграции защищены проверкой платформы; Android/iOS-папки и ключ подписи
намеренно не включены в веб-репозиторий.

## Изменения 1.0.12

- Удалён ошибочный отказ при фотографиях больше 48 Мп; добавлены уменьшение
  через ImageBitmap и резервное чтение файла.
- Ошибки чтения фотографии сообщают безопасный код этапа, без самой фотографии.
- Версия в API-запросах и диагностике берётся из package.json.
- Сохранены кеширование данных и плавное повторное переключение основных страниц.

Полный аудит старых зависимостей и существующих lint-замечаний не входит
в эту точечную правку. Отдельно требуется устранить временное сохранение пароля
в localStorage при регистрации (унаследованный код биометрической настройки).
